# ყდა — წარწერების სახელოსნო

სწრაფი ხელსაწყო პერსონალიზებული ზღაპრების ყდებისთვის. ქართული ინტერფეისი, მობილური და კომპიუტერი. მუშაობს მთლიანად ბრაუზერში; სერვერი, რეგისტრაცია, API გასაღები და ფასიანი გენერაცია არ სჭირდება.

## გამოყენება

1. ჩაწერე სათაური. აირჩიე 1, 2, 3 ხაზი, ავტომატური გადანაწილება ან საკუთარი Enter-ები.
2. აირჩიე თემა, შრიფტი და 3D მასალა. „ახალი კომბინაცია“ იმავე თემაში ცვლის ვიზუალს. საკეტებით შეგიძლია სასურველი პარამეტრები შეინარჩუნო.
3. დააჭირე „PNG ჩამოტვირთვა“ ან „კოპირება“. PNG ყოველთვის გამჭვირვალეა. Canva-ში ჩასვი დაკოპირებული სურათი ან ატვირთე ჩამოტვირთული PNG.

## რა არის ჩაშენებული

- 86 ნამდვილი შრიფტი: 44 GeoLab + 42 Slava Meskhi; ძველი კოდირება ადაპტირებულია ქართულ Unicode-ზე. შრიფტი მხოლოდ არჩევისას იტვირთება.
- დამატებითი TTF, OTF, WOFF და WOFF2 ფაილების ატვირთვა, ცოცხალი შრიფტის გალერეა.
- 30 განსხვავებული თემატური ვექტორული ორნამენტი და 5 ჩარჩოს ფორმა.
- 25 ვიზუალურად განსხვავებული 3D მასალა, 15 პალიტრა და 100 მზა იდეა.
- ქართული და მეორე ენაზე ტექსტის ცალ-ცალკე შრიფტი, ზომა, განლაგება და დაშორება.
- ტექსტის ავტომატური ჩატევა, ზუსტი ხაზების რაოდენობა, მასალის სიღრმე, კონტური, ჩრდილი, ბზინვარება და ფერადი ასოები.
- თემაში შემთხვევითი კომბინაციები, პარამეტრების საკეტები, ფერის/სტილის/ჩარჩოს ცალკე ცვლა და 5-წამიანი ავტორეჟიმი. ხელით შეცვლა, შენახვა და ექსპორტი ავტორეჟიმს აჩერებს.
- უკან/წინ, რჩეულები, ბრაუზერში ავტომატური შენახვა და გადასატანი `.yda.json` პროექტები (პირადი შრიფტებისა და საცდელი ფოტოს ჩათვლით).
- ყდის ფოტოზე განთავსების წინასწარი ხედი. ფოტო PNG-ში არ შედის.
- საერთო რენდერერი ჩამოტვირთვისა და კოპირებისთვის: ტექსტი/ჩარჩო/ორივე, მაღალი გარჩევადობა, გამჭვირვალე სივრცის მოჭრა და კიდის ზომა.

3D ეფექტები Canvas 2D-ით გამოითვლება. ეს არის მოცულობითი ტიპოგრაფიკა და ვექტორული დეკორი; ტექსტის დასაწერად გენერაციული AI არ გამოიყენება. მორგებული შრიფტის უცნობი სიმბოლო ბრაუზერის დამხმარე შრიფტით შეიძლება გამოჩნდეს. ფონტის არსებულ დიზაინს პროგრამა არ ცვლის.

## GitHub Pages

Settings → Pages → **Deploy from a branch** → **main** → **/(root)** → Save.

მთავარი `index.html` პირდაპირ რეპოზიტორიის ძირეულ საქაღალდეშია; build არ სჭირდება. `.nojekyll` გამორთავს Jekyll-ის დამუშავებას. მთელი აპი ფარდობით მისამართებს იყენებს, ამიტომ `/yda/` მისამართზეც მუშაობს.

## შემოწმება და განვითარება

```sh
node --test tests/*.test.mjs
python3 -m http.server 8000
```

გახსენი `http://localhost:8000/`. რენდერერის ინტეგრაციული ტესტები: `/tests/browser.html`; რეალური iframe-ის მობილური ზომები: `/tests/mobile.html` (320, 390 და 768 px).

ტესტები ამოწმებს Unicode-ს, ღ/ლ-ს განსხვავებას, 86 შრიფტის ჩატვირთვას, 30 თემის და 25 მასალის განსხვავებას, ხაზების ზუსტ რაოდენობას, ორენოვან განლაგებას და PNG-ის ნამდვილ alpha-არხს.

კოპირება საჭიროებს HTTPS-სა და ბრაუზერის Clipboard მხარდაჭერას; წარუმატებლობისას აპი მომხმარებელს PNG ჩამოტვირთვას სთავაზობს. Canva-ში ჩასმის ქცევა დამოკიდებულია ბრაუზერსა და Canva-ს მიმდინარე ვერსიაზე.

PNG-ის მაქსიმუმია 14 მილიონი პიქსელი და 6000 px ერთ მხარეს, რათა ტელეფონის მეხსიერება არ გადაიტვირთოს. ბეჭდვის სანტიმეტრები 300 dpi-ზე გამოთვლილი საორიენტაციო ზომაა; ფაილი პიქსელურ გარჩევადობას ინახავს.

ბრაუზერის მონაცემების წაშლა შლის ლოკალურ პროექტსა და რჩეულებსაც. მნიშვნელოვანი პროექტი შეინახე ფაილად. მონაცემები, პირადი ფოტოები და დამატებული შრიფტები ქსელში არ იგზავნება.

შრიფტების წყაროსა და Unicode ადაპტაციის შესახებ: [FONT-NOTES.md](assets/fonts/FONT-NOTES.md). ორიგინალი კრებულების ZIP ფაილები რეპოზიტორიაში არ ინახება.
